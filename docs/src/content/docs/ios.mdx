## Deployment target

Use an iOS deployment target supported by your Flutter SDK. Current Flutter
projects use iOS 15.0 or later.
[Flutter's iOS support table](https://docs.flutter.dev/reference/supported-platforms#ios)

For an existing app, set **iOS Deployment Target** on the Runner target in
Xcode. If you use CocoaPods, match that version in `ios/Podfile`.

```ruby
platform :ios, '15.0'
```
