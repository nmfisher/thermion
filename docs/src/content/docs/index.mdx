Thermion brings 3D rendering to Dart and Flutter. Load a glTF model, light
and animate it, and display it on mobile, desktop, or the web.

[Show your first model in Flutter](/quickstart/)

## Live examples

Use the dropdown to switch scenes. Drag the scene to look around, or
[open the full gallery](/gallery/).

<ThermionShowcase />

## Use it at the level you need

- Start with `ViewerWidget` to display a model in a Flutter app.
- Use `ThermionViewer` to [build a scene](/viewer/) and control its models,
  cameras, lighting, and animation.
- Use `FilamentApp` for [multiple views or headless rendering](/build_configuration/#render-with-filamentapp).
