## Minimum SDK

Keep the minimum SDK supplied by Flutter. In a new project,
`android/app/build.gradle.kts` sets it as follows.

```kotlin
defaultConfig {
    minSdk = flutter.minSdkVersion
}
```

If you set a custom minimum, choose an API level supported by your Flutter
version and at least API 22 for Thermion.
[Flutter's Android support table](https://docs.flutter.dev/reference/supported-platforms#android)
