title: Windows
description: Run Thermion on Windows via the Direct3D 11 plugin.

Thermion supports Windows via a Direct3D 11 texture plugin
(`thermion_flutter/windows`). Filament renders into a D3D11 texture that
Flutter embeds as a platform view, so no ANGLE/GLES workaround is required.

## Requirements

- Windows 10 (or later)
- Visual Studio 2022 with the **Desktop development with C++** workload
  (includes CMake and the Windows SDK)
- CMake 3.14 or newer (bundled with VS 2022)

## Running

```
flutter run -d windows
```

As with other platforms, the first build downloads the prebuilt Filament
binaries (see [Getting Started](/getting_started/)). These are cached under
`.dart_tool/`, so subsequent builds are faster — run `flutter clean` to force a
re-download.

## Notes

- The Windows plugin targets C++20 and is built with
  `CMAKE_WINDOWS_EXPORT_ALL_SYMBOLS`.
- A fresh checkout may not have `generated_headers.cmake` until the build hook
  runs. If a `flutter run` appears stuck on first configure, run `flutter test`
  once to fire the hook out of band, then retry.
- For a Flutter-less, pure Dart + native window setup, see
  `examples/dart/cli_windows` (Windows-only).
