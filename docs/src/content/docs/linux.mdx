---
title: Linux
description: Thermion support and limitations on Linux.
---

Thermion runs on Linux desktop (experimental). The `thermion_flutter` package ships a
Linux plugin that bridges Filament to a Flutter window using Vulkan (Wayland), with an
OpenGL/EGL path as a fallback.

It has been built and tested on Ubuntu 22.04; other distributions may work, but your
mileage may vary.

## System dependencies

The Filament 1.76.0 archives are built with LLVM/libc++ 18. Use Clang 18 and
the matching libc++ development and runtime libraries. Ubuntu 22.04's default
libc++ 14 cannot link these archives: it lacks `__libcpp_verbose_abort`, which
is used when C++ exceptions are disabled.

On Ubuntu 22.04, first enable the LLVM 18 packages using the instructions at
[apt.llvm.org](https://apt.llvm.org/). Then install the build dependencies:

```bash
sudo apt install clang-18 libc++-18-dev libc++abi-18-dev cmake ninja-build pkg-config libgtk-3-dev liblzma-dev libdrm-dev libegl1-mesa-dev
export PATH="/usr/lib/llvm-18/bin:$PATH"
```

Deployed applications also need a compatible libc++ runtime; the documented
LLVM 18 setup supplies it through `libc++1-18` and `libc++abi1-18`.

## Running

```bash
flutter run -d linux
```

The `quickstart`, `picking`, `viewer`, and `animations` examples under
`examples/flutter/` all build and run on Linux.

:::note
Linux support is still experimental. If you hit rendering or windowing issues, please
report them — and contributions are welcome. [Join us on Discord](https://discord.gg/h2VdDK3EAQ)
if you'd like to help.
:::
