title: Light and style a scene

Start with the viewer from [Build a scene](/viewer/). Add a light to see the
model, then adjust how its surfaces reflect that light.

<span id="direct-lights"></span>

## Add a light

A sun lights the whole scene from one direction. For a light with a location,
use `DirectLight.point` or `DirectLight.spot`. A point light shines in all
directions. A spot light shines in a cone. Use this sun in place of the one
from the scene setup if you're following along.

```dart
final sun = await viewer.addDirectLight(
  DirectLight.sun(castShadows: true, direction: Vector3(-0.5, -1, -0.3)),
);

final lamp = await viewer.addDirectLight(
  DirectLight.point(
    position: Vector3(3.5, 2.5, 2.0),
    intensity: 90000,
    falloffRadius: 8.0,
  ),
);
```

<span id="modifying-lights"></span>

Keep the returned light handle so you can move or remove it. Call
`viewer.setLightPosition(lamp, x, y, z)` or `viewer.removeLight(lamp)`.
Use `viewer.setLightDirection(sun, direction)` to aim a sun or spot light.
Change color, intensity, and falloff with `viewer.app.lightManager`.
Sun intensity is measured in lux, point light intensity in lumens, and
spot light intensity in candela.

<span id="skybox-and-backgrounds"></span>

## Light a model with an environment

Image-based lighting (IBL) uses an image of the surroundings to light the
model and provide reflections. A skybox displays the background. You can use
either on its own or load both from the same environment.

```dart
await viewer.loadIbl('assets/studio_ibl.ktx');
await viewer.loadSkybox('assets/studio_skybox.ktx');
```

Thermion includes [sample environment files](https://github.com/nmfisher/thermion/tree/develop/examples/assets)
with names ending in `_ibl.ktx` and `_skybox.ktx`. Use Filament's `cmgen`
tool to turn your own high dynamic range image into a matching pair.

Use `rotateIbl` to turn the lighting or `setBackgroundColor` for a plain
background. Loading a new IBL replaces the active one. If you call
`removeSkybox()`, you own the returned skybox and its texture.

## Add shadows

Shadows need a view with shadows enabled, a light that casts them, an object
that blocks the light, and a surface to catch the shadow. With the sun above,
add a ground plane beneath the model you've already loaded as `asset`.

```dart
final ground = await viewer.createGeometry(
  GeometryUtils.plane(width: 10, height: 10),
);
await ground.setReceiveShadows(true);
await asset.setCastShadows(true);

await viewer.setShadowsEnabled(true);
await viewer.setShadowType(ShadowType.PCF);
```

<span id="shadow-types"></span>
<span id="per-light-shadow-options"></span>

Start with `ShadowType.PCF`. For softer edges, try `DPCF` or `PCSS` and
adjust `viewer.view.setSoftShadowOptions(...)`. A directional light also
supports cascaded shadow maps through `viewer.app.lightManager.setShadowOptions`.

<span id="troubleshooting"></span>

If shadows are missing, check the view, the light, and both objects first.
For striped self-shadowing, raise the bias slightly. For a shadow that lifts
off its object, lower the bias. Increase the map size if the edges are
pixelated.

## Change a material

A material defines how a surface looks. A material instance gives it specific
values such as a color, roughness, or texture. A glTF model already brings
its own materials. To replace them, create a material instance and apply it
to the asset.

```dart
final material = await viewer.app.createUbershaderMaterialInstance();
await material.setParameterInt('baseColorIndex', -1);
await material.setParameterFloat4('baseColorFactor', 0.0, 0.7, 0.3, 1.0);
await asset.setMaterialInstanceForAll(material);
```

Use `createUnlitMaterialInstance()` for a flat material that ignores lighting.
You can read or replace an individual primitive's material with
`getMaterialInstanceAt()` and `setMaterialInstanceAt()`.

Wireframe, stencil highlights, and flat shading need geometry prepared at
load time. Request `SceneAssetGeometryCapability.barycentrics` in
`loadGltf(..., requiredGeometryCapabilities: {...})` for assets that use those
features. This adds vertex data, so enable it per asset.

<span id="textures"></span>

## Add a texture

In Flutter, load the image with `rootBundle` from `package:flutter/services.dart`.
Decode it and upload the pixels into a texture. The glTF material above samples
the texture through `baseColorMap` when `baseColorIndex` is `0`.

```dart
final bytes = await rootBundle.load('assets/paint.png');
final image = await viewer.app.decodeImage(
  bytes.buffer.asUint8List(bytes.offsetInBytes, bytes.lengthInBytes),
);
final texture = await viewer.app.createTexture(
  await image.getWidth(),
  await image.getHeight(),
);
await texture.setLinearImage(image, PixelDataFormat.RGBA, PixelDataType.FLOAT);
final sampler = await viewer.app.createTextureSampler();
await material.setParameterInt('baseColorIndex', 0);
await material.setParameterTexture('baseColorMap', texture, sampler);
```

Dispose of images, textures, samplers, and material instances you own when
you're finished with them. The
[materials and textures sample](https://github.com/nmfisher/thermion/tree/develop/examples/flutter/materials_and_textures)
shows image loading and material swaps in a runnable app.
