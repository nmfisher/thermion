---
title: Contributing
description: Contribute to the Thermion project.
---

Thermion is an open source project and all contributions are welcome, no matter the level of experience.

Please [join us on Discord](https://discord.gg/h2VdDK3EAQ) if you'd like some guidance or just want to chat.

To help generating changelogs & versioning from commit messages, please use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) if you wish to submit a PR.
