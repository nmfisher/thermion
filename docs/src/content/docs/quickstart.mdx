This guide puts a 3D model on screen in a Flutter app. Drag it to look around
and scroll or pinch to zoom.

<span id="setup"></span>

## Set up your app

Use Flutter 3.44 or later. Check the setup for [your desktop or mobile platform](/platforms/)
or [running on the web](/web/#flutter). From your Flutter project, add Thermion.

```bash
flutter pub add thermion_flutter
```

If you're starting from scratch, run `flutter create model_viewer` and open
that directory first.

## Add a model

Save a `.glb` file as `assets/model.glb` in your app. You can use
[Thermion's sample cube](https://raw.githubusercontent.com/nmfisher/thermion/develop/examples/assets/cube.glb).
Add the file to the existing `flutter` section of `pubspec.yaml`.

```yaml
flutter:
  assets:
    - assets/model.glb
```

Use the same path in `ViewerWidget`. A `.glb` file usually packages the model
and its textures together, which makes it convenient for this example.

<span id="example"></span>

## Display it with ViewerWidget

Replace `lib/main.dart` with this app. `ViewerWidget` loads the model, positions
the camera, and handles orbit controls. A sun light makes the model visible.

```dart
import 'package:flutter/widgets.dart';
import 'package:thermion_flutter/thermion_flutter.dart'
    show DirectLight, ViewerWidget;

void main() {
  runApp(
    WidgetsApp(
      color: const Color(0xFF000000),
      builder: (context, child) => ViewerWidget(
        assetPath: 'assets/model.glb',
        directLight: DirectLight.sun(),
      ),
    ),
  );
}
```

## Run the app

```bash
flutter devices
flutter run -d <device-id>
```

The first build can take a while while Thermion downloads its engine libraries.
For Chrome, use the [web run command](/web/#flutter), which includes the headers
the engine needs.

If Flutter reports a missing asset, check that the file exists at the exact
path in both `pubspec.yaml` and the Dart code. Restart the app after changing
the asset list.

## Adjust the view

- The default camera orbits the model. Set `manipulatorType` to
  `ManipulatorType.NONE` for a fixed camera or `ManipulatorType.FREE_FLIGHT`
  for free movement. You can change this property while the widget is running.
- Set `iblPath` to light the model with a `.ktx` environment. Set `skyboxPath`
  to show the matching background. Add both files to your Flutter assets.
- See the [ViewerWidget API](https://pub.dev/documentation/thermion_flutter/latest/)
  for the full list of properties.

## Control the scene yourself

Use `onViewerAvailable` to access the viewer that `ViewerWidget` creates.
When you want to own model loading, cameras, and input, follow
[Build a scene](/viewer/). For more examples, browse the [gallery](/gallery/).
