Use Flutter 3.44 or later on the stable channel.

## Prerequisites

For a native app, the build hook compiles Thermion against prebuilt Filament
libraries. Install the build tools for your target platform.

| Platform | Setup |
| --- | --- |
| macOS | Xcode and a macOS deployment target of 13.0 or later. |
| iOS | Xcode and the [iOS deployment settings](/ios/). |
| Android | Android SDK and the [Android minimum SDK setting](/android/). Flutter fetches the required NDK. |
| Windows | [Windows build tools](/windows/#requirements). |
| Linux | [Linux system dependencies](/linux/#system-dependencies). |
| Web | The build hook fetches the prebuilt [WebAssembly engine](/web/). |

## Setup

From your Flutter project, add `thermion_flutter`.

```bash
flutter pub add thermion_flutter
```

For macOS, set the Runner deployment target in Xcode to macOS 13.0 or later.
If you use CocoaPods, match that target in `macos/Podfile`.

![Xcode deployment target settings](/images/macos_min_deployment.png)

Run the app with `flutter run -d <device>`, using the device ID from
`flutter devices`.

:::note
The first build downloads the prebuilt binaries and caches them under
`.dart_tool/`.
:::
