---
title: Debugging
description: Diagnose Thermion builds and runtime behavior.
---

Thermion uses release libraries by default, including when you run your app in
Flutter debug mode. To use debug libraries and tracing, add these settings to
your app's `pubspec.yaml`.

```yaml
hooks:
  user_defines:
    thermion_dart:
      mode: debug
      tracing: enabled
```

If a Flutter build keeps using the previous settings, run `flutter clean`
and rebuild.

:::caution
Debug builds won't work for Android. This is a known upstream issue with Filament.
:::
